# TDCSG carrier-line plates

These plates are generated by PILean from the phase records in `Exact.lean`.
The exact theorem `commonEdge_collinear` proves that the prescribed polygon
scale makes the selected right-polygon edge collinear with the global origin;
the companion edge is its half-turn.  The theorem
`n10_carrierEndpoint_contact` supplies the separate order-10 disk-contact
identity.

From `PILean/Gallery`:

```sh
lake build tdcsg-carrier-lines
lake exe tdcsg-carrier-lines
```

Outputs are written under `out/tdcsg-carrier-lines/`:

- `n10-common-edge.png` — the exact `j=3,6` decagon geometry and closed lens
  carriers at the published squared radius `4-phi`;
- `n20-common-edge-atlas.png` — the five polygon scales required by all ten
  standard-orientation common-edge phases; and
- `n20-common-edge-focus-j09-j10.png` — the `j=9,10` phase pair annotated with
  the four carrier-meeting candidates from the existing bounded diagnostic.

Each render writes a certificate beside the PNG.  The order-20 disks use the
retrospective depth-four contact radius, not a proved critical radius.  The
`j=9,10` annotations are bounded carrier-intersection evidence, not certified
first returns or an IET.  The separate `54 deg` origin-ray experiment is not a
standard-orientation polygon-edge line and is intentionally absent.
